# InfraMap — как править и публиковать

Ссылки проекта **постоянные** — при правках они не меняются:

- **Демо (сайт):** https://daurenonline.github.io/Astana-city/
- **Презентация:** https://daurenonline.github.io/Astana-city/presentation-2026.html
- **Репозиторий:** https://github.com/daurenonline/Astana-city

---

## Что за какой файл отвечает

| Файл | Что это |
|---|---|
| `index.html` | Сам сайт-прототип (карта, EVM, аудит, риски, документы, RFI) |
| `presentation.html` | **Каноническая презентация** — правьте её |
| `presentation-2026.html` | Страница-редирект на `presentation.html` (этот адрес стоит в заявке; сам файл менять не нужно) |
| `qr-mvp.svg` | QR-код на живой прототип (встроен в презентацию и сайт) |
| `README.md`, `*_FINAL.md`, `*_PACK.md` | Документы проекта и текст заявки |
| `kontur_region/` | Серверная часть (Frappe-приложение) — этап пилота |

**Вывод:** для правок контента трогайте только `index.html` и `presentation.html` — по ссылкам сразу обновится.

## Как опубликовать правку (2 способа)

### Способ 1. Через меня (рекомендую)
Пришлите текст/правку — я внесу, закоммичу и запушу, сайт обновится через 1–2 минуты.

### Способ 2. Самостоятельно (терминал)
```powershell
cd "C:\Users\Пользователь\Documents\Default Project\g-ton"
git add .
git commit -m "Правка презентации/сайта"
git push origin main
```

### Способ 3. Через браузер без терминала
Открыть файл на GitHub → карандаш (Edit) → внести правки → **Commit changes**.
GitHub Pages пересоберётся автоматически.

## Важно про кэш

В проект встроен «kill-switch»: страницы сами снимают регистрацию service worker и чистят кэш, поэтому свежая версия показывается всегда. Если у кого-то всё же видно старое — достаточно **Ctrl + Shift + R** (жёсткая перезагрузка).
