# МЦПК — карта семи КПП

Отдельная страница проекта InfraMap. Основа: Leaflet и OpenStreetMap.

## Данные
- Семь автомобильных КПП Казахстан — Узбекистан.
- Период: 2026-09-23 — 2026-10-22. Один календарный интервал для всех пунктов.
- Источник: публичные атрибуты `data-chart-options` графика «Производительность поста» CarGoRuqsat; серия строго «Пересёк пункт пропуска».
- Выгружено 23.10.2026. Исходные публичные HTML сохранены в папке проекта локально; SHA-256 и извлеченные наблюдения — в source-audit.json.
- На четырех КПП есть дневной ряд; на трех график не публикует этот ряд. Это не нулевой поток.
- Среднее, медиана и сумма считаются по числовым наблюдениям. Пропуски исключаются из знаменателя, покрытие показывается отдельно. Динамика — последние 7 календарных дней против первых 7, только если оба окна полные и начальное среднее положительно.
- Числа отражают учет CarGoRuqsat, не весь двусторонний поток, не бронирования и не загрузку проектной мощности. Направление/охват требуют уточнения у оператора.
- Координаты унаследованы из сохраненной карты со ссылками на Mapcarta/OSM; это точки комплексов, не кадастровые границы. Для Ялламы отдельно указана сторона границы.

## Открытие
Откройте index.html. Для подложки карты и Leaflet требуется интернет. Таблица, ряды и выгрузка CSV встроены и работают без отдельного сервера.

## Файлы
- index.html — интерактивная карта, карточки, графики, сводная таблица.
- data.json — согласованный набор данных.
- daily.csv — все 7 × 30 строк; пропуски пустые, не нули.
- source-audit.json — источники, точные x/y из диаграмм, даты и контрольные суммы.
